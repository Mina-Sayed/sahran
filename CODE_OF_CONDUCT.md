# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give feedback on the work and not the person, and don't harass anyone.

Report problems privately to the maintainers using GitHub's "Report a vulnerability / contact" options on this repository, or by email at the address in the maintainer's GitHub profile. Reports are handled confidentially.
