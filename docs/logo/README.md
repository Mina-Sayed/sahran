# Logo

A closed laptop with one eye open on the lid and light leaking from the seam: still awake, lid closed.

| File | Use |
|---|---|
| `icon.svg`, `icon-512.png` | App icon, avatar, favicon |
| `banner.svg`, `banner.png` | README header |
| `social-preview.png` (1280x640) | GitHub: Settings > Social preview |

Colours: night `#0d1420`, paper `#ebe7dc`, lamp `#f6b73c`.

The wordmark is converted to outlines, so it renders the same everywhere without fonts. Typefaces: DM Serif Display (Latin), Amiri (Arabic) and Lato (tagline), all under the SIL Open Font License 1.1. The logo files are released under the same MIT license as the project.
